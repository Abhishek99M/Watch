# Aurel Veil V11 - dial signature and surface clarity

Original vector-outline AUREL wordmark, small folded-V emblem, and VEIL subtitle replace all raster lettering on the dial. Applied lettering is part of the actual GLB and is preserved during separation. No installed-font dependency or image overlay.

Lug tops remain brushed while flanks and bevels are polished. Fitted end pieces have narrower lateral clearance. Curved bracelet faces are retained, with fewer unnecessary bevel subdivisions and explicit MikkTSpace tangents on anisotropic geometry. Metal roughness and normal textures remain embedded.

Corrected the crystal thickness from 0.00065 to 0.65 in local millimeter coordinates beneath the 0.001 root scale. IOR 1.46 with reduced specular is an artistic glass/coating approximation, not measured sapphire. Browser inspection uses a 1.5-2 pixel ratio and 1.25 transmission target scale; this trades performance for clarity. Studio review cameras disable depth of field. Dial grain remains JPEG-compressed; lettering is geometry and has no JPEG artifacts.

## Validation and limitations
check-detail.cjs validates actual signature geometry, explicit anisotropic tangents, glass thickness and root scaling. The browser check verifies the live viewport/transmission resolution settings. Existing optics, playback, browser/reassembly, mobile overflow, and delivery checks are retained. Size and triangle count are in manifest.json. Real-device performance, production compression, and website integration remain pending. No numerical visual rating is treated as a test result.

## GitHub source package

GitHub includes the approved master, procedural geometry/material scripts, review
viewer, its vendor dependencies and MIT notices, HDR/credits, and final renders.
Start the review server from the repository root with
`node prototypes/atelier/serve.cjs`, then open the delivery URL above.
`node scripts/prepare-watch.mjs` rebuilds the website derivative from the pinned
master without needing Blender or the historical studies.

V1-V10, historical comparison pages, portable Blender, intermediate base GLBs,
and generated .blend scenes stay local and are excluded by .gitignore. Nothing
was deleted. The render script can recreate studio scenes with a separately
installed Blender. Regenerating the master is a design change and requires
reviewing/updating its pinned hash; do not replace it merely to rebuild the web GLB.
