# UI and UX

Use restrained editorial typography, a coherent spacing scale, high contrast, premium material imagery and minimal motion. Avoid neon overload, excessive gradients and random glass effects.

Build reusable navigation, buttons, section headings, product cards and loading/error states. Mobile menus must be keyboard accessible and close with Escape. Controls need labels and visible focus.

Check widths 320, 375, 390, 768, 1024, 1440 and 1920 pixels. Prevent overflow, overlapping text, unusable controls and layout shifts. Reserve image dimensions.

Respect prefers-reduced-motion: minimize camera travel, smooth scrolling and loops while preserving information and configuration. Use static content when WebGL fails. Pause offscreen animation and cap rendering cost on mobile.
